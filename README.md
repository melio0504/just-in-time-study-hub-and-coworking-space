# Just In Time Study Hub and Coworking Space

_A modern study hub and coworking space experience built with Next.js._

![Project preview](public/images/solo-learner.jpg)

## Overview

Just In Time Study Hub and Coworking Space is a responsive web app for a study and coworking venue in Manila. It highlights the space, key amenities, pricing, reservation flow, gallery, and virtual tour experience in a polished landing-page style interface.

## Features

- Homepage with a strong hero section and call to action
- Sections for venue highlights, features, pricing, and contact-oriented information
- Route pages for About, Account, Gallery, Login, Pricing, Register, Reserve, and Virtual Tour
- Built with reusable UI components and modern React patterns

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- Radix UI components
- Lucide icons, Motion, and other supporting UI libraries

## Project Structure

- `app/` contains the Next.js App Router pages and shared layout
- `app/components/` contains reusable UI components
- `public/images/` stores the image assets used throughout the site

## Getting Started

### Prerequisites

- Node.js 18 or newer
- npm

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
```

### Start the Production Server

```bash
npm run start
```

### Lint the Project

```bash
npm run lint
```

## How to Create a Pull Request on GitHub

1. Create a new branch for your changes.
2. Make and test your updates locally.
3. Commit your changes with a clear message.
4. Push the branch to your GitHub repository.
5. Open the repository on GitHub and click Compare & pull request.
6. Add a title and description that explain what changed and why.
7. Review the files, request reviewers if needed, and submit the pull request.
8. Respond to feedback, make any follow-up commits, and push them to the same branch.
9. Once approved, merge the pull request using the repository’s preferred merge option.

### Suggested Git Naming Convention

- Branch name: `feature/add-homepage-gallery`
- Commit message: `feat: add homepage gallery section`
- Other common patterns: `fix:`, `docs:`, `style:`, `refactor:`, `test:`, `chore:`
